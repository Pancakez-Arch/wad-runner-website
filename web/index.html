Controls
↑ ↓ ← →Move / turn
MouseClick the game to capture; move to turn and look up/down. Esc releases.
PgUp / PgDn, EndLook up / down, re-centre view
Ctrl or left clickFire
Space or right clickOpen doors / use switches
ShiftRun
W SWalk forward / back
A D or Alt + ←/→Strafe left / right
1–7Select weapon
TabAutomap
EscMenu
F2 / F3Save / load game (saves are kept in this browser)

Phone/tablet: on-screen controls appear automatically. Tap Fullscreen and turn the phone sideways. RUN toggles on and off; WPN cycles weapons; Y answers yes/no prompts.

Tip: use Fullscreen so the browser doesn't catch keys like Ctrl+W. Music uses the OPL (AdLib/Sound Blaster) synth with the instruments from your WAD.

Engine: doomgeneric (based on Chocolate Doom / id Software's Doom source), GPL-2.0, see LICENSE.txt. No game data is included.
